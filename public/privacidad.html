Política de Privacidad

Última actualización: Septiembre de 2026

1. Recopilación y Uso de Datos

Geniochat es una extensión para el navegador que opera de forma local. No almacenamos, leemos, recopilamos ni transmitimos tus conversaciones de WhatsApp, contactos ni datos personales a servidores externos nuestros. Todo el CRM, respuestas rápidas, historial y catálogos de productos se guardan estrictamente en el almacenamiento local de tu navegador (Local Storage).

2. Uso de Inteligencia Artificial (Google Gemini)

La función de "Copilot AI" requiere que el usuario ingrese su propia clave de API de Google Gemini. Cuando decides analizar un mensaje, únicamente el texto de ese mensaje específico se envía de forma segura a través de la API oficial de Google para generar las sugerencias de respuesta. Geniochat no guarda un historial de estas interacciones ni almacena tus claves de API en ningún servidor propio.

3. Permisos de la Extensión

Geniochat solicita permisos mínimos y estrictamente necesarios para funcionar:

  • Acceso a web.whatsapp.com: Exclusivamente para superponer nuestra interfaz de herramientas sobre la página web y facilitar tu gestión.
  • Almacenamiento (Storage): Para guardar tus configuraciones y datos del sistema CRM localmente en tu computadora.

4. Descargo de Responsabilidad de Plataforma

Geniochat es un software independiente desarrollado para optimizar la productividad del usuario. No está afiliado, asociado, autorizado, respaldado por, ni de ninguna manera conectado oficialmente con WhatsApp LLC, Meta Platforms Inc., o cualquiera de sus subsidiarias o afiliadas.
